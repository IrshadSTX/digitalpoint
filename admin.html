Admin Sign In

Sign in to manage the content and images on the Digital Point website.

How do I get an access token?
  1. Sign in to GitHub with the account that owns the website, then open New fine-grained token.
  2. Give it a name (for example Website admin) and choose an expiry date.
  3. Under Repository access, choose Only select repositories and pick digitalpoint.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it and paste it above.

Keep the token private, because anyone who has it can edit the website. Only tick "Keep me signed in" on your own device.
